This motivates a real experiment; the fixed-time counterfactual does not establish a performance benefit. Neither the phone buffer nor an encoded dependency queue needs changing to test it.

`udp_lan_gateway.py` now accepts `--owner-raw-queue-policy latest` only with physical LAN scope, the existing explicit private capture trace and the existing bounded gateway lifetime. FIFO is the default. Tailnet or public NPS latest, missing trace, unknown policy and invalid types fail before worker/device startup; no policy is accepted from an HTTP session body or inherited environment. `udp_nps_gateway.py` and all deployed services are unchanged. The worker receives the explicit local policy, forwards it to the existing `HostHardwareSession` and emits a requested-policy readback in the listener/cleanup report. Requested readback alone is not proof of actual frame decisions; actual hardware summary and bounded trace must be checked.

Only complete pre-encode raw RGBA frames may be superseded. No new App is needed for this host experiment and no APK/default has changed. The candidate does not enable a friend/public option.
