# M5 视频应用、广告过滤与手机媒体互传

部署日期：2026-09-29。环境为现有 M5 的 Android17/API37、KernelSU3.3.0、Zygisk Next1.5、Vector2.2/API102；原虚拟机、用户、TLS证书和NPS15556映射保留。

## 已安装与配置

红果7.3.9.32、快手14.8.30、优酷11.2.15、爱奇艺17.9.5、腾讯视频9.04.55、NewPipe0.29.1、VLC3.7.1。保留原抖音、哔哩哔哩与系统YouTube20.10.41。官方/开源下载来源、签名和校验值见研究文档与evidence/apk-audit.json。尚未取得TikTok官方APK；没有安装未知MOD包。Netflix等订阅DRM平台没有当作已验证兼容的软件。

FanqieHook0.8.5仅启用红果作用域。现场日志30个hook安装、3个番茄搜索AI清理项不适用，免费推荐短剧真实播放。此结果证明模块在该版本加载和基本播放正常，不证明整个推荐流或所有插播100%去广告；金币和内部促销界面仍可能出现。模块屏蔽奖励广告时不会发放服务器确认的奖励。

bindhosts2.1.5使用mode2普通bind。Mac经验证证书的HTTPS获取AdAway+AWAvenue，解析去重生成7377域名；关闭安卓侧sources与cron，避免其wget降级不校验证书。没有额外VPN/代理。普通App（UID10246、未授权su）读取到7377规则，googleads.g.doubleclick.net解析0.0.0.0，爱奇艺/腾讯/YouTube首页HTTPS200。Android内正常域名解析有Clash TUN fake-IP，这是既有网络状态；远程15556连接和NPS通道照常独立验证。

优酷、爱奇艺、腾讯没有安装无法审计源码的专用综合hook。DNS可过滤独立广告域名，不能承诺同域流内贴片清除。付费登录、DRM和真实手机长时间播放仍需分平台验收。

## v1.8 媒体互传

客户端新增登录页“照片 · 视频互传”，底部加入“文件”。手机用系统OpenDocument选择照片视频（一次最多20个），虚拟安卓文件可通过CreateDocument保存回手机。沿用原用户名密码、服务器地址、TLS证书及15556端口。上传到Download/火锅互传并同步MediaStore扫描。浏览DCIM/Pictures/Movies与互传目录的公共媒体；不用root读取私有App目录。

互传时暂停串流释放带宽，从串流进入时返回会重新连接。单文件上限1GB，服务器一次一项传输，最多列出500个媒体文件；当前版本不支持断点续传，断开后重传。上传随机命名避免覆盖，SHA256两端核对，服务器临时文件与登录保护、规范路径检查防止目录越界；不新增公网ADB或匿名文件服务器。

真实Android17客户端系统文件选择器完成上传，系统保存选择器完成下载，下载图744197字节与上传图SHA256一致。后续真实一加手机安装与移动网络实际表现不能由该虚拟客户端测试替代。

LAN192.168.9.99与公网146.56.249.175均实际验证PNG与H264 MP4上传、下载，哈希一致、MediaStore扫描、列表可见。未登录401、非媒体415、超过1GB413、路径越界拒绝；符号链接规范路径限制有单元验证。临时测试账号删除，账号仍2个；ADB5037和5555仍仅监听回环。

安全边界测试与磁盘错误后占用释放共7项通过；客户端release构建和完整lintRelease通过，仍有非阻断的本地化/可访问性等警告。手机升级通过原App“检查更新”，由Android系统进行最后安装确认。

原生预测返回接口已适配Android16/17，避免使用已停止分发的旧onBackPressed回调。官方说明：https://developer.android.com/about/versions/16/behavior-changes-16。
