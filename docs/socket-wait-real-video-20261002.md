# 第二层发送等待的真实视频对照，2026-10-02

本轮把原先同时改变 pacing 与 guard 的组合实验拆开：A 保留 Python socket 定时等待；B 只关闭这层等待。两者保留相同的发送预算预留、序列化检查、帧截止时间、参考链保护与 C++ 原生分片 pacing。这里是下一版 UDP 管线的独立实验，不改变正式 App 的 TLS/TCP 服务。

源端为 M1 的 `emulator-5556`，6 核／16 GiB／物理 1080×1920。实时读回 guest min/peak 为 60 Hz，不能称为 120 Hz 内容。Morphe YouTube 播放公开视频 `aqz-KE-bpKQ`；每轮重启测试播放器、请求 seek 60 s、预热 15 s，质量菜单明确读回 `1080p60`，播放前后与源端呈现仍需分别验证。菜单标签本身不是 60 个不同解码帧的证明。

本批串流编码为 **720×1280、VBR 8 Mbps**，原生线路预算 32 Mbps，native/socket catchup 2048 字节；原生／raw／接收上限 120，手机屏幕请求 120 Hz；FIFO、提交提前量 0、缓冲 80 ms，声音及原生触控通道开启。原生通道开启没有代表此次已做手势操作。本批没有注入丢包。

连接路径为 M1 `en7 192.168.9.128` → 一加 12 Wi-Fi `192.168.9.149` 的 AES-GCM UDP **物理局域网**。没有通过公网 NPS、Tailscale 或东北 V50。手机继续保留用户的 CPU 限制；本轮没有写入频率、移除限制器或清除播放器数据。

顺序为两组 ABBA，共 8 次 120 s 实际视频接收。主要窗口为手机第一份认证包后的 `[5,110)`，源端为自身第一份呈现后的 `[5,110)`；两个窗口各自计数，绝不相减不同设备的 monotonic 时钟。每轮 105 s，合计 840 s，独立 SurfaceFlinger 时间序列记录实际新呈现，而非解码回调 FPS、截图或目标帧率。

A 平均手机 **58.340476 FPS**，源端 **58.385714 FPS**；B 平均手机 **59.804762 FPS**，源端 **59.828571 FPS**。手机大于 100 ms 的间隔合计 A 28、B 0；大于 80 ms 的间隔 A 52、B 3。两个 ABBA 区块均观察到 B 的更好表现，值得保留为候选。

但源端也同时改善约 1.443 FPS，与手机改善约 1.464 FPS 接近，输入不是同一份编码字节的重放。手机第 1、2、6、7 轮的 CPU 上限前后读回还发生过变化，观察进程未写这些值；前后读回不构成持续恒定的限频证明。因此这是重复出现的关联，不能把全部收益解释为第二层 sleep 单独造成的因果改善。下一批采用同等的 5 s 只读 CPU 上限观察，记录状态波动而不强行锁频。

第一轮约 290 ms 手机长空档已经用 PTS 身份串联：同域相邻 gRPC 图像返回间隔 306.551 ms、packetizer intake 间隔 319.667 ms、手机完整 AU 接收间隔 325.891 ms。对应两个原生帧的累计 sleeps 只有 0.380/1.507 ms。这个空档包含源端供给中断，不能说成苹果硬件解码运行了 300 ms，也不能说 Python 单次 sleep 了 290 ms。分析使用帧身份和各自时域的相邻间隔；capture 与 packetizer 的绝对 monotonic 数值存在偏移，不作绝对减法。

所有轮次 socket deadline／参考链／不完整输出累计均为 0。A5 的接收 FEC `frames_expired` 和 `reference_lost` 各为 2，其余 7 轮为 0。所有手机详细 native ring 都裁掉约前 49–52 s，早期没有单帧详细事件不能当成没有问题；全程累计接收计数仍可用。各轮 packetizer 最新累计快照都是 `final=false`，不把它们误称完整结束快照。

音频 A 合计 worker-late 1698，B 45，但 A1 单轮贡献 1651。排除这个离群轮，A 过期比例约 0.2776%，B 0.1994%；不能据此宣布音画同步已解决。本轮没有声学或光学唇形同步测量。下一项独立诊断只拆分 arrival age、PTS 顺序、输入缓冲截止等原因，并记录 codec 输出持有时长，不改 80 ms 播放策略。

本次长视频期间保留正常宿主服务。第一块测试时有两次约 0.175/0.334 s 的轻量离线更新回归检查，第二块没有重复执行；没有 Gradle 重建、安装 APK 或人工操作手机穿插于八轮接收。报告保留这个边界，不宣称完全无后台任务的实验室条件。
